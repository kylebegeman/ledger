# Ledger v0.9.5

## Summary

A redesigned reader for the history behind your code. This release introduces
Overview, Records, and Timeline views, a more focused browsing experience,
blue light and dark themes, and a new visual identity. The rewritten README
includes a recorded walkthrough and a live example built from this repository.

## Public Notes

- Explore repository history in three views: Overview for recent changes,
  activity, releases, and health; Records for focused search and filtering;
  and Timeline for a chronological view grouped by month.
- Browse with compact record rows, rounded filter controls, and custom dropdown
  menus. The desktop sidebar groups record types and deeper filters, while
  smaller screens keep those controls within reach above the results.
- Read the evidence beside a change: its rationale, invariants, verification,
  files, and linked decisions. Step between records without closing the panel,
  expand the relationship map when needed, and use the command palette and
  keyboard shortcuts to navigate.
- Use near-white light mode or charcoal/slate dark mode, both with blue accents.
  The reader follows your system preference until you choose Light or Dark,
  then remembers that choice across visits.
- Meet Ledger's new punched-receipt icon and wordmark. The README now leads with
  a 24-second recorded tour, a shorter setup path, and examples for supported
  coding agents.
- Try the [live reader](https://kylebegeman.github.io/ledger/) and
  [public changelog](https://kylebegeman.github.io/ledger/changelog/), rebuilt
  from the project's records on every push to master. Public releases have
  direct links and an Atom feed.
