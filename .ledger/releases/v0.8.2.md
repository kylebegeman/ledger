# Ledger v0.8.2

## Summary

Drafts fit the change. Hook drafts and `ledger new --from-diff` take symbols
and anchors only from the lines a diff changed. A `ledger ci` run before the
turn ends lists the failing files and names the session whose hook will draft
their receipt. `ledger release --update` adds a late receipt to an existing
release record. Drafts no longer crash in projects on TypeScript 7 or on
TypeScript 5.0 to 5.4. Dependencies and actions are current.

## Public Notes

- Hook drafts and `ledger new --from-diff` list only the symbols a change touched. Each file's anchors are the declarations or the innermost Markdown section that hold a changed line, headings inside fenced code are ignored, and a file whose change sits outside every symbol keeps a TODO anchor. New files still list their symbols, up to twelve.
- `ledger ci` prints each failing file with the reason, not just counts. When a Claude Code, Codex, or Cursor session touched a file that coverage or docs impact reports, `ci`, `coverage`, and `docs impact` name that session and its draft receipt, and say to finish the draft rather than run `ledger new`. The checks still fail until the receipt is finished, and GitHub annotations leave these hints out. The JSON output of all three commands gains a `sessions` list.
- `ledger release <version> --include-unreleased --assign --update` adds receipts that landed after a release record was written to its `entries` and `## Changes`, and keeps the summary, public notes, verification, and known issues you wrote. `--write` still refuses to overwrite a record.
- Symbol extraction no longer crashes next to TypeScript 7, which ships no JavaScript API: drafts fall back to the regex extractor, and `ledger doctor` says why. Installing `@typescript/typescript6` beside TypeScript 7 restores parsed symbols, and TypeScript 5.0 to 5.4 now parse too.
- The MCP SDK is 1.30.0, zod is 4.6.5, and yaml is 2.9.1, and the composite GitHub Action pins `actions/setup-node` v7.0.0.
- The README gives the measured cost of running hooks through npx, about 0.3 seconds per hook, and how an installed copy avoids it.
