# Ledger v0.3.2

## Summary

First release since v0.3.1 to reach npm. Carries the Windows test
portability fixes and newest-first reader ordering that landed in July, records
the accepted next-version direction and retired proposals, and fixes the release
pipeline so tags publish and produce GitHub Releases.

## Public Notes

- The static reader and its search index now list records newest-first on both
  the internal and public profiles, and the command palette shows the most
  recent records.
- Tests pass on Windows as well as macOS and Linux.
- The roadmap gains Phase 11, the local memory engine direction, and records
  which earlier proposals were retired.
- Tagged releases publish to npm through trusted publishing and create a GitHub
  Release from the release record. Homebrew instructions were removed until a
  tap exists, and development now happens through pull requests into master.
- Release records now require a Public Notes section, and the internal render
  total budget is 2,500,000 bytes.

## Verification

- `npm run ci` on Node 24 locally and across the Ubuntu, macOS, and Windows
  matrix for Node 22 and 24 in pull request CI
- `node dist/cli.js render --json` within budget for the internal profile
- Review the verification sections in the listed Ledger entries.

## Known Issues

- Publishing depends on npm trusted publishing being configured for
  `kylebegeman/ledger` and `release.yml`, or on an `NPM_TOKEN` secret; the
  workflow fails at the publish step until one exists and can be re-run.
