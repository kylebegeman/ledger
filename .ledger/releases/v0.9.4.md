# Ledger v0.9.4

## Summary

Freshness, corrected. `ledger stale` stopped reading a record as drift when the
record simply pointed at its files by pattern, by directory, or by path. The
fixes came out of triaging the first outside adopter's stale report, where 156
of 169 signals named symbols that are in the tree.

## Public Notes

- `ledger stale` now searches the files a record's coverage patterns cover. A record that lists `src/**` or `plugins/*/adapter.json` beside a few exact files no longer reports the symbols and anchors that live under the pattern as drift: the patterns become Git `:(glob)` pathspecs searched with `git grep`. When the search cannot run, because Git is missing or a pathspec is unusable, the pattern reports nothing rather than guessing.
- A Changed Files heading that names a directory path, such as `### internal/composer, CHANGELOG.md`, now covers the record's files under that directory, so the block's anchors are checked against them. A heading word without a path separator, as in "Tests, skill, and docs", stays prose.
- An anchor that names a path the tree still holds, by full path, by a file name under some directory, or as a directory itself, is a reference to that file rather than content to find inside another. A bare file name counts only when its tail looks like an extension, so a member name such as `Server.throttle` is still checked as a member name.
- Together these take the stale report on a 12,000 file repository from 169 signals to 14. The pattern search runs once per record and block file list and only for records that name patterns, so `ledger stale` and `ledger doctor` take about 15 seconds on a tree that size, against well under a second where receipts list exact files.
