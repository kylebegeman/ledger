# Ledger v0.6.0

## Summary

Capture. Records now get written by the workflow: host hooks for Claude Code,
Codex, and Cursor start a session record, track touched paths, inject a
memory packet, and draft a receipt; a shipped skill and a managed `AGENTS.md`
block tell agents how to use Ledger; authoring commands create every record
kind; `ledger ready` gates drafts before they land.

## Public Notes

- `ledger hooks install --host claude-code|codex|cursor` installs lifecycle hooks into the host's project hook file. A session starts with a budgeted Ledger packet, every edit is recorded on a session record, stop drafts a change entry from the touched paths and the Git diff, and pre-compaction writes a handoff so the next context window keeps the same memory. Nothing auto-starts the engine.
- `ledger skills install` writes `.agents/skills/ledger/SKILL.md` (with a `.claude/skills/ledger` link for Claude Code) so skills-aware agents know when to call `packet`, `explain`, `session note`, `new`, `promote`, and `ready`. `ledger agents --write` maintains the same workflow as a fenced block in `AGENTS.md`.
- Session records: a new short-lived `session` kind under `.ledger/sessions/` with `ledger scratch`, `session start|touch|note|close|prune`, a configurable expiry (`sessions.expiresInDays`, default 7), an `expired-session` stale signal, and promotion into a change entry with `ledger promote S000N`.
- `ledger ready` distinguishes a valid draft from one ready to land: TODO markers, template placeholders, empty sections, missing Verification or Invariants bullets, unreviewed docs impact, and missing references are reported with line numbers, and the command exits 1.
- Authoring commands: `ledger backlog new`, `ledger decision new`, `ledger promote <id>` (carries acceptance checks into Verification and updates the item in one transaction), and `ledger release notes <version>` (prints a record's Public Notes). Backlog and decision id widths are configurable (`ids.backlogWidth`, `ids.decisionWidth`).
- Library: `createBacklogItem`, `createDecision`, `promoteRecord`, `readReleaseNotes`, `draftChangeEntry`, session helpers, `checkReadiness`, hook and skill installers, and frontmatter editing helpers are exported from the package root; `ledger_ready` and `ledger_release_notes` join the MCP tools.
